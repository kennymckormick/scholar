# 119位学者的发表与引用

这是固定于 **2026-10-16** 的 Google Scholar 记录快照，覆盖固定名单119人。发表与引用排除明确专利；引用保留GS估算值，2026年未满年。一作仅计已确认本人首位署名，数量和累计引用为下界。

站点默认匿名，支持实名切换、九张图的放大与下载，以及按需加载个人逐篇证据。通过静态网页服务打开 `index.html` 即可使用，无需构建或登录。

- `index.html`：交互主表与九图展示。
- `formal/`：匿名／实名PNG、九图总览、下载ZIP与图片清单。
- `evidence/`：119人的逐篇证据JSON。
- `scholar_master.csv`：119行、169列主表；字段说明见 `field_definitions.csv` / `.json`。
- `statistics.json`：九项统计；`analysis.json` 及其他CSV／JSON保存分析和审计结果。

所有站内资源使用相对路径，可部署在 GitHub Pages 的 `/scholar/` 子路径。空 `.nojekyll` 用于直接提供静态文件。机构和职级沿用PDF原文分组，不代表论文发表时的任职或已归一的真实机构实体。
